# Wireshark-Basic
# Wireshark Networking Basics

Beginner-friendly hands-on notes and labs for learning **packet analysis, TCP/UDP, DNS, QUIC, and HTTP** using Wireshark.

This repository is designed for students interested in **Networking, Cybersecurity, DevOps, and System Administration**.

---

## 📌 What You Will Learn

* IP addressing (Source & Destination IP)
* Ports & well-known services
* Linux network interfaces
* Packet capturing with Wireshark
* TCP 3-way handshake
* UDP & DNS analysis
* QUIC protocol (YouTube traffic)
* HTTP GET & POST inspection
* Why HTTP is insecure

* Wireshark

## ▶ Getting Started

1. Install Wireshark
2. Select your active network interface
3. Start capturing packets
4. Apply display filters (tcp, udp, dns, http)
